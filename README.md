# richard-costa.github.io

Source for [richard-costa.github.io](https://richard-costa.github.io/) — my personal website for projects, technical notes, and posts.

Built with [Quarto](https://quarto.org/).

## Run locally

```bash
quarto preview
```

## Repository map

- `index.qmd` — homepage and selected work
- `notes/` — technical notes and references
- `posts/` — chronological posts
- `files/` — résumé and other static downloads
- `theme.scss` — site styling
- `_quarto.yml` — site-wide configuration
